# Editorial articles

The active [blog writing guide](../content/writing/README.md) covers authoring and
preview. The [component reference](../content/writing/components.md) defines
the tags and fields. [The decision record](../decisions/blog-authoring.md)
explains the default layout and publication boundary.

Astra's implementation uses a 680px reading column and selected 864px figures,
a disclosure cover with a second composition in the body, and separate related
reading and reference cards. The non-sticky sidebar uses small image or document
nodes. Selecting a node updates the card below. The design demo remains available
at `/__drafts/editorial/`.
