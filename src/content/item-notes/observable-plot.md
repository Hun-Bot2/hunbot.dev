## 무엇인가
Observable Plot은 표 형태의 데이터를 시각화하기 위한 무료 오픈소스 JavaScript 라이브러리입니다. 탐색적 데이터 분석을 빠르게 하는 것을 목표로 하며, 짧은 코드로 표현력 있는 차트를 만들 수 있게 설계되었습니다. 웹에서 데이터를 그려 보려는 개발자, 데이터 분석가, 저널리스트에게 적합합니다.

## 이럴 때 쓴다
- CSV나 JSON 데이터를 받아 분포와 추세를 빠르게 확인할 때
- D3를 직접 다루기엔 번거로운 간단한 차트를 만들 때
- 블로그나 노트북에 데이터 시각화를 덧붙일 때
- 같은 데이터를 여러 방식으로 바꿔 가며 탐색할 때

## 핵심 기능
- **마크(Marks)**: 점, 선, 막대, 영역 같은 도형 요소를 겹쳐 쌓아 차트를 구성합니다.
- **스케일(Scales)**: 데이터 값을 위치와 색 등 시각 속성으로 대응시킵니다.
- **그래픽 문법 접근**: 스케일과 레이어드 마크를 중심으로 한 구성 방식을 따릅니다.
- **간결한 API**: 적은 설정으로 기본값이 합리적인 차트를 얻도록 설계되었습니다.
- **갤러리와 문서**: 공식 문서와 예제 갤러리에서 다양한 사용 예를 확인할 수 있습니다.

## 시작하는 법
공식 문서(observablehq.com/plot/)의 시작 안내를 따라 설치하고, 예제 갤러리에서 비슷한 차트를 찾아 데이터에 맞게 고쳐 보는 방법이 가장 빠릅니다. 이 노트를 작성할 때 확인한 소개 페이지에는 설치 명령과 코드 예제가 직접 실리지 않았으므로 구체적인 설치법은 문서에서 확인해야 합니다.

## 알아둘 점
- 저장소의 라이선스는 ISC로 표기됩니다(GitHub 기준).
- 표 형태 데이터의 시각화에 초점을 맞춘 라이브러리입니다.
- Observable이라는 플랫폼 이름이 붙어 있지만 라이브러리 자체는 오픈소스로 공개되어 있습니다.
