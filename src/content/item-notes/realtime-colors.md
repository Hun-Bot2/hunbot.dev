## 무엇인가
Realtime Colors는 색상과 폰트 조합을 실제 웹사이트 같은 화면에 바로 적용해 보며 고를 수 있는 웹 도구입니다. 팔레트를 추상적인 색 견본이 아니라 완성된 레이아웃 위에서 확인하므로, 웹 디자이너와 프런트엔드 개발자가 사이트의 색 체계를 정할 때 쓰기 좋습니다. @Juxtopposed가 만든 것으로 소개됩니다.

## 이럴 때 쓴다
- 새 프로젝트의 브랜드 색과 폰트 조합을 빠르게 비교할 때
- 텍스트와 배경의 대비가 접근성 기준을 만족하는지 확인할 때
- 정한 팔레트를 CSS나 Tailwind 설정으로 바로 내보내고 싶을 때
- 다크 모드와 라이트 모드에서 색이 어떻게 보이는지 점검할 때

## 핵심 기능
- **색 선택 단계**: 글자·배경용 중립색 두 개, 주색과 보조색, 강조색을 차례로 고릅니다.
- **배색 규칙**: 단색, 유사색, 보색, 분할 보색, 삼색, 사색 조합과 무작위 생성을 제공합니다.
- **폰트 설정**: Google Fonts 또는 로컬 폰트로 제목과 본문 폰트, 타입 스케일을 정합니다.
- **대비 검사기**: 색별 대비율을 보여 주고 AA·AAA 충족 여부를 신호색으로 표시합니다.
- **내보내기**: CSS, Tailwind CSS, SCSS와 HEX, RGB, HSL, OKLCH 등의 형식을 지원하며 DaisyUI, shadcn, Material UI 프리셋도 있습니다.
- **부가 도구**: Figma 플러그인과 VS Code 테마 편집기가 언급됩니다.

## 시작하는 법
사이트에 접속하면 미리보기 화면이 바로 열립니다. 툴바에서 색과 폰트를 바꿔 가며 화면에 어떻게 보이는지 확인하고, 마음에 드는 조합이 나오면 Export 버튼으로 코드나 파일을 내려받거나 복사합니다. 다크/라이트 전환으로 두 모드를 모두 확인할 수 있습니다.

## 알아둘 점
- 사이트는 완전 무료라고 소개하며, 요금제 표시는 Basic, Pro, Enterprise 모두 0달러입니다(2026-10 기준). Pro와 Enterprise에는 대시보드 접근 같은 추가 혜택이 적혀 있습니다.
- 생성한 색은 상업적으로 사용할 수 있다고 안내됩니다.
- 내보내기 형식 중 PNG, ZIP, QR 코드는 소개 문구에만 언급되어 있어 실제 동작은 직접 확인이 필요합니다.
