## 무엇인가
Uiverse는 커뮤니티가 올린 UI 요소를 CSS나 Tailwind 코드로 모아 둔 오픈소스 라이브러리입니다. 버튼, 체크박스, 토글 스위치, 카드, 로더, 입력창, 라디오 버튼, 폼, 패턴, 툴팁 같은 카테고리가 있습니다. 직접 컴포넌트를 처음부터 만들지 않고 가져다 쓰려는 프런트엔드 개발자와 디자이너를 위한 곳입니다.

## 이럴 때 쓴다
- 독특한 로더나 토글 같은 작은 UI 요소를 빠르게 프로젝트에 넣고 싶을 때
- CSS 애니메이션과 효과를 코드로 참고해 배우고 싶을 때
- Tailwind로 작성된 컴포넌트 예시가 필요할 때

## 핵심 기능
- **카테고리 탐색**: 요소 종류별 목록과 페이지 단위 둘러보기
- **CSS와 Tailwind 코드**: 각 요소를 두 방식 중 하나의 코드로 제공합니다
- **커뮤니티 기여**: 제작자들이 각자 작품을 올립니다
- **Figma 활용**: 외부 리뷰는 요소를 Figma 디자인에도 가져다 쓸 수 있다고 설명합니다

## 시작하는 법
uiverse.io의 카테고리에서 원하는 요소를 고른 뒤 코드를 복사해 프로젝트에 붙여 넣는 방식으로 씁니다. 요소 페이지에서 CSS 또는 Tailwind 코드를 확인할 수 있습니다. 구체적인 UI 조작 순서는 이번 조사에서 직접 확인하지 못했습니다.

## 알아둘 점
- 사이트 푸터는 게시된 UI 요소가 MIT 라이선스라고 밝힌다고 검색 결과에서 확인되었습니다 (2026-10 기준).
- 요소마다 개별 제작자가 올리므로, 실제 사용 전에는 해당 요소 페이지나 제작자 안내에서 출처 표기 조건을 확인하는 편이 안전합니다.
- 외부 리뷰는 3,500개 이상의 컴포넌트가 있다고 소개하지만, 공식 수치는 확인하지 못했습니다.
- 사이트 본문(403 응답) 접근이 제한되어 일부 내용은 검색 결과와 외부 리뷰에 의존했습니다.
