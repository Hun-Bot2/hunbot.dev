## 무엇인가
Vega-Lite는 JSON으로 시각화를 선언하는 고수준 그래픽 문법입니다. 데이터의 필드를 점이나 막대 같은 마크의 시각 속성에 대응시키는 명세를 쓰면, 축, 범례, 스케일은 컴파일러가 기본 규칙으로 자동 생성합니다. 데이터 분석가와 웹 개발자가 짧은 코드로 차트를 만들고 인터랙션까지 붙일 때 쓰입니다.

## 이럴 때 쓴다
- 코드 몇 줄의 JSON으로 막대, 선, 산점도 같은 차트를 빠르게 만들 때
- 하나의 명세로 여러 차트를 겹치거나 나란히 놓는 다중 뷰를 구성할 때
- 선택 기능으로 차트 간 연동 인터랙션을 넣을 때
- 더 세밀한 제어가 필요해 Vega로 넘어갈 준비를 할 때

## 핵심 기능
- **마크와 인코딩**: 데이터를 마크의 위치, 색, 크기 등에 매핑합니다
- **데이터 변환**: 집계, 구간화, 필터링, 정렬
- **시각 변환**: 스태킹과 패싯(분할 보기)
- **합성**: 레이어링과 다중 뷰 구성
- **선택(Selections)**: 차트를 인터랙티브하게 만드는 기능

## 시작하는 법
공식 사이트의 Get started 튜토리얼과 Try online 에디터로 시작하는 방법이 안내됩니다. 웹 페이지에 넣는 방법은 사이트의 Usage 섹션과 embed 안내에 정리되어 있습니다. npm 패키지 `vega-lite`로도 배포됩니다. 이번 조사에서는 구체적인 설치 코드까지는 문서에서 확인하지 못했습니다.

## 알아둘 점
- 사이트에 표시된 최신 버전은 6.5.0입니다 (2026-10 기준).
- GitHub 저장소의 라이선스는 BSD-3-Clause입니다.
- Vega-Lite는 저수준의 Vega 명세로 컴파일되므로, 복잡한 경우에는 Vega로 옮겨 갈 수 있습니다.
