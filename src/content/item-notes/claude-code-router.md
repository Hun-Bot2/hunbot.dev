## 무엇인가
Claude Code Router(CCR)는 코딩 에이전트가 쓰는 모델 호출을 로컬 게이트웨이 한 곳으로 모아 관리하는 도구입니다. Claude Code를 비롯해 Codex, OpenCode 같은 에이전트가 하나의 로컬 엔드포인트를 바라보게 하고, 제공자, 모델, 계정, 라우팅 규칙을 한곳에서 설정합니다. 에이전트에 다른 제공자의 모델을 연결하거나 상황별로 모델을 나눠 쓰려는 개발자를 위한 것입니다.

## 이럴 때 쓴다
- Claude Code에서 다른 제공자(OpenRouter, DeepSeek 등)의 모델을 쓰고 싶을 때
- 요청 조건에 따라 모델을 나누고, 실패하면 다른 모델로 넘기고 싶을 때
- 여러 API 키를 돌려 쓰거나 키별 사용 한도를 두고 싶을 때
- 어떤 모델과 키로 처리됐는지, 지연과 토큰 사용량을 로그로 확인하고 싶을 때

## 핵심 기능
- **에이전트 프로필**: 여러 에이전트별로 모델 재정의와 환경 설정을 관리합니다.
- **제공자 연결**: 프리셋과 커스텀 엔드포인트, 모델 탐색, 연결 확인을 지원합니다.
- **라우팅**: 헤더·본문 조건, 요청 재작성, 재시도, 순서 있는 폴백 모델을 지원합니다.
- **접근 제어**: 만료일과 요청·토큰 한도를 가진 별도의 클라이언트 키를 발급합니다.
- **관측성**: 상태, 지연, 토큰, 추정 비용, 도구 호출을 기록합니다.

## 시작하는 법
데스크톱 앱 설치가 권장 방식입니다. 앱에서 Providers에 제공자를 추가하고, Server에서 시작하면 게이트웨이가 `http://127.0.0.1:3456`에서 동작합니다. 이후 Agent Config에서 에이전트와 모델을 골라 적용합니다. CLI로는 다음과 같이 시작합니다.

```
npm install -g @musistudio/claude-code-router
ccr ui
```

관리 UI는 `http://127.0.0.1:3458`에서 열립니다. 상세 설정 문서는 저장소가 안내하는 ccrdesk.top에 있다고 합니다.

## 알아둘 점
- 라이선스는 MIT입니다.
- CLI는 Node.js 22 이상이 필요합니다.
- Docker로 외부에 노출하기 전에 Docker 가이드를 먼저 읽으라고 안내합니다.
- 지원 에이전트와 제공자 목록은 계속 바뀔 수 있으므로 저장소의 최신 내용을 확인해야 합니다(2026-10 기준).
