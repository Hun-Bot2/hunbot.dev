## 무엇인가
CSS Loaders는 로딩 애니메이션 600여 개를 모아 둔 사이트입니다. 각 로더는 CSS만으로 만들어졌고 요소 하나로 구성되어 있어, 별도 스크립트나 복잡한 마크업 없이 붙일 수 있습니다. Temani Afif가 만들었으며 같은 제작자의 CSS Pattern, CSS Shape 등과 연결되어 있습니다.

## 이럴 때 쓴다
- 이미지나 라이브러리 없이 가벼운 로딩 스피너가 필요할 때
- 서비스 분위기에 맞는 로더 모양을 여러 후보에서 고르고 싶을 때
- 단일 요소 CSS로 도형 애니메이션을 만드는 방식을 배우고 싶을 때

## 핵심 기능
- **44개 카테고리**: 점, 막대, 스피너, 도형, 3D, 진행 표시, 클래식 등으로 나뉩니다.
- **단일 요소 구조**: 기본 마크업은 `<div class="loader"></div>` 하나입니다.
- **클릭 복사**: 로더를 클릭하면 해당 CSS가 복사됩니다.
- **무작위 선택**: 버튼으로 다른 로더를 무작위로 볼 수 있습니다.

## 시작하는 법
카테고리를 둘러보다 마음에 드는 로더를 클릭해 CSS를 복사합니다. 그다음 페이지에 `loader` 클래스를 가진 요소를 하나 두고 복사한 스타일을 붙이면 됩니다.

```html
<div class="loader"></div>
```
