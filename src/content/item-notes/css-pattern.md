## 무엇인가
CSS Pattern은 CSS 그라디언트로 만든 배경 패턴을 모아 둔 사이트입니다. 이미지 파일 없이 CSS만으로 배경 무늬를 넣고 싶은 웹 개발자와 디자이너를 위한 것입니다. 메인 페이지에는 157개의 패턴이 있다고 적혀 있고, 앞으로 계속 늘어난다고 안내합니다. 제작자는 Temani Afif이며 CSS 변수로 값을 조정할 수 있게 다듬었다고 소개합니다.

## 이럴 때 쓴다
- 이미지 요청 없이 가벼운 배경 무늬를 쓰고 싶을 때
- 허니콤, 곡선, 겹친 큐브 같은 패턴 중에서 어울리는 것을 고르고 싶을 때
- 그라디언트만으로 반복 무늬를 만드는 CSS 기법을 참고하고 싶을 때

## 핵심 기능
- **패턴 목록**: 각 패턴마다 "Get the CSS" 링크로 개별 페이지가 연결됩니다.
- **CSS 변수 기반**: 값을 바꿔 색이나 크기를 조정하도록 만들어졌다고 설명됩니다.
- **무작위 패턴 선택기**: 임의의 패턴을 하나 보여 줍니다.
- **관련 프로젝트 링크**: CSS Loaders, CSS Shape, CSS Generators 등 같은 제작자의 사이트로 이어집니다.

## 시작하는 법
메인 목록에서 패턴을 고른 뒤 "Get the CSS"로 해당 페이지에 들어가 CSS를 가져와 요소의 `background` 관련 속성에 적용하는 흐름으로 보입니다. 다만 개별 페이지의 구체적인 복사 방식은 이번 조사에서 직접 확인하지 못했습니다.

## 알아둘 점
- 메인 페이지에는 라이선스나 이용 조건이 적혀 있지 않았습니다. 상업적 사용 전에 제작자의 안내를 확인하는 것이 좋습니다.
- 브라우저 지원 범위 등의 제한도 해당 페이지에서는 확인되지 않았습니다.
