## 무엇인가
One Page Love는 한 페이지로 구성된 웹사이트(싱글 페이지 사이트)의 디자인을 모아 보여 주는 갤러리입니다. 메인 페이지 기준으로 2008년부터 직접 골라 모았다고 소개하며, 약 9천 개의 사이트와 9천 개 이상의 섹션 사례가 올라와 있습니다. 랜딩 페이지나 소개 페이지를 만들려는 디자이너와 개발자가 레퍼런스를 찾을 때 유용합니다.

## 이럴 때 쓴다
- 제품 랜딩 페이지의 구성과 카피 흐름 사례를 찾을 때
- 포트폴리오나 개인 사이트를 만들기 전에 분위기를 잡을 때
- 히어로, 가격표 같은 특정 섹션만 따로 참고하고 싶을 때
- SaaS, 앱, 스타트업 등 장르별로 비슷한 사이트를 비교할 때

## 핵심 기능
- **Inspiration 컬렉션**: 전체 사이트를 둘러보는 기본 갤러리입니다.
- **Sections 컬렉션**: 사이트 전체가 아니라 섹션 단위의 사례를 모아 둡니다.
- **장르 태그**: 랜딩 페이지, 스타트업, 포트폴리오, 앱, SaaS, 실험적 사이트 등으로 걸러 볼 수 있습니다.
- **개별 사이트 페이지**: 각 항목에서 "Launch website" 링크로 실제 사이트에 바로 갈 수 있습니다.
- **뉴스레터**: "The Love Letter"가 2주마다 발송됩니다.

## 시작하는 법
메인 페이지에서 Inspiration이나 Sections를 열고 장르 태그로 범위를 좁혀 가며 둘러봅니다. 마음에 드는 항목은 개별 페이지에서 실제 사이트로 이동해 직접 확인합니다. 목록은 페이지 단위로 이어지며 "Next"로 넘길 수 있습니다.

## 알아둘 점
- 일부 항목에는 "Sponsored" 표시가 붙으며, 웹사이트 빌더가 추천 항목으로 노출되는 모습이 메인 페이지에서 확인됩니다.
- 메인 페이지에는 사이트 제출 방법과 이용 가격이 나와 있지 않습니다.
- 페이지 제목에는 폰트와 템플릿이 언급되지만, 메인 페이지에서는 그 자료의 구체적인 내용이 확인되지 않았습니다.
