## 무엇인가
Refero는 실제로 출시된 웹과 iOS 제품의 화면을 모아 둔 디자인 레퍼런스 라이브러리입니다. 외부 소개 자료에 따르면 400개 이상의 제품에서 나온 12만 5천 장 이상의 화면이 있고 매주 추가됩니다. 디자이너와 팀, 그리고 AI 에이전트가 실제 제품 사례를 근거로 디자인을 결정할 때 쓰도록 만들어졌습니다.

## 이럴 때 쓴다
- 가입, 온보딩, 해지, 결제 같은 화면 흐름이 다른 서비스에서 어떻게 구성되는지 비교할 때
- 특정 페이지 유형이나 UI 요소의 실제 사례를 폭넓게 모아 볼 때
- 비슷한 화면을 이미지 업로드로 찾고 싶을 때
- AI 코딩 도구에게 실제 제품 사례를 참고시켜 디자인 품질을 높이고 싶을 때

## 핵심 기능
- **화면 라이브러리**: 페이지 유형, 흐름, UX 패턴, UI 요소, 카테고리, 폰트별로 정리된 스크린샷
- **검색과 필터**: 태그, 회사, 폰트, 색상 등으로 검색하고 이미지로 유사 화면을 찾습니다
- **사용자 흐름**: 단계별로 이어진 여정 단위의 화면 모음
- **Figma 플러그인**: Figma 안에서 레퍼런스를 불러옵니다
- **Refero MCP와 Skill**: AI 에이전트가 라이브러리를 조회하는 MCP 서버와 디자인 방법론 지침 계층

## 시작하는 법
웹사이트에서 검색과 필터로 화면을 둘러보는 것이 기본입니다. AI 도구와 연결하려면 문서에 따라 MCP 서버 주소 `https://api.refero.design/mcp`를 사용합니다. ChatGPT나 Codex는 플러그인 디렉터리에서 설치하는 방법이 가장 쉽다고 안내하며, Claude Code나 Cursor 등은 문서의 설정 예시를 따릅니다. 인증은 도구에 따라 OAuth 또는 Bearer 토큰입니다.

## 알아둘 점
- 무료 등급이 있는 프리미엄 모델로 소개되지만, 구체적인 요금은 확인하지 못했습니다. 요금은 공식 가격 페이지에서 확인해야 합니다.
- MCP 연동에는 Pro, Team, Lifetime 중 하나의 유료 플랜이 필요합니다 (2026-10 기준).
- 해당 플랜은 사용자당 월 최대 8,000회의 MCP 도구 호출을 포함하며, 남은 횟수는 이월되지 않습니다.
- 학생은 40% 할인을 신청할 수 있다고 외부 자료에 소개되어 있습니다.
