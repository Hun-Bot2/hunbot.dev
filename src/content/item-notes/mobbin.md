## 무엇인가
Mobbin은 실제로 출시된 모바일 앱, 웹 앱, 웹사이트의 화면과 흐름, UI 패턴을 모아 검색할 수 있게 한 라이브러리입니다. 제품 디자이너, 개발자, 앱을 만드는 팀이 "다른 서비스는 이 문제를 어떻게 풀었는가"를 조사할 때 씁니다. AI 도구가 이 라이브러리를 검색할 수 있게 하는 연동도 제공합니다.

## 이럴 때 쓴다
- 온보딩, 결제, 구독 같은 다단계 흐름이 실제 앱에서 어떻게 구성되는지 비교할 때
- 빈 상태, 다이얼로그, 폼, 페이월 등 특정 UI 요소의 사례를 모을 때
- 랜딩 페이지의 히어로, 가격표, 푸터 같은 섹션 레퍼런스를 찾을 때
- 팀에서 참고 화면을 컬렉션으로 공유하며 디자인 방향을 논의할 때

## 핵심 기능
- **화면(Screens)**: 모바일과 웹의 개별 화면을 볼 수 있습니다.
- **흐름(Flows)**: 여러 단계로 이어지는 사용자 여정을 순서대로 보여 줍니다.
- **패턴과 요소**: 내비게이션, 표, 빈 상태 같은 UI 요소별로 모아 둡니다.
- **검색과 필터**: 앱, 화면 속 텍스트, 패턴, 플랫폼, 산업, 카테고리로 찾을 수 있습니다.
- **컬렉션과 Figma**: 참고 자료를 컬렉션에 저장하고, 해당 요금제에서는 Figma로 복사할 수 있습니다.
- **MCP와 REST API**: AI 도구의 검색 연동(MCP)과 맞춤 통합용 REST API를 제공합니다.

## 시작하는 법
mobbin.com/signup에서 무료 계정을 만든 뒤 mobbin.com/explore에서 라이브러리를 탐색합니다. 플랫폼이나 카테고리로 범위를 좁히고, 필요한 화면은 컬렉션에 저장합니다. 전체 라이브러리 이용은 상위 요금제가 필요합니다.

## 알아둘 점
- 요금제는 Free, Pro, Team, Enterprise로 나뉩니다. Free는 라이브러리 접근이 제한되고, Pro 이상에서 전체 라이브러리와 MCP를, Team 이상에서 REST API를 쓸 수 있다고 안내됩니다(2026-10 기준).
- 메인 페이지에는 구체적인 가격과 사용량 한도가 적혀 있지 않아 mobbin.com/pricing에서 확인해야 합니다.
- 금융 앱 모음인 Finance+는 Team과 Enterprise에서 추가로 이용하는 애드온입니다.
- 새 콘텐츠는 매주 추가된다고 소개됩니다.
