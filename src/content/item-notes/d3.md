## 무엇인가
D3(Data-Driven Documents)는 데이터를 바탕으로 맞춤형 시각화를 만드는 JavaScript 라이브러리입니다. Mike Bostock과 Observable이 개발합니다. 완성된 차트 템플릿을 고르기보다 SVG나 HTML을 데이터에 연결해 원하는 모양을 직접 그리려는 개발자를 위한 도구입니다.

## 이럴 때 쓴다
- 막대, 선, 파이 차트를 세밀하게 커스터마이징하고 싶을 때
- 트리맵, 포스 다이어그램, 코드 다이어그램 같은 특수한 레이아웃이 필요할 때
- 지도 투영을 바꿔 가며 지리 데이터를 시각화할 때
- 줌, 드래그, 브러시 같은 상호작용을 차트에 붙일 때

## 핵심 기능
- **선택과 전환(selections, transitions)**: 데이터에 맞춰 DOM을 만들고 갱신하고 애니메이션합니다. 가상 DOM은 쓰지 않습니다.
- **스케일과 축**: 데이터 값을 위치, 크기, 색으로 대응시키고 축을 그려 줍니다.
- **도형 생성기**: 호, 영역, 곡선, 선, 파이, 스택, 심볼 같은 기하 요소를 만듭니다.
- **레이아웃**: 트리맵, 트리, 포스, 보로노이, 원 패킹 등을 제공합니다.
- **지도 투영**: 다양한 구면 투영을 지원합니다.
- **유틸리티**: CSV 파싱, 날짜 포맷, 색 공간, 통계 함수 등이 포함됩니다.

## 시작하는 법
npm으로 설치하거나 CDN 스크립트로 불러옵니다.

```bash
npm install d3
```

```js
import * as d3 from "d3";
d3.select("body").append("p").text("Hello, D3!");
```

공식 사이트의 Get started 문서와 Observable에 올라온 예제 갤러리에서 코드를 이어서 확인할 수 있습니다.

## 알아둘 점
- 사이트에 표시된 최신 버전은 7.9.0이고 라이선스는 ISC입니다(2026-10 기준).
- 더 빠르게 차트를 만들고 싶다면 같은 팀의 상위 수준 API인 Observable Plot이 있다고 소개되어 있습니다.
- 메인 페이지에는 설치 명령이 직접 적혀 있지 않았으며, 위 명령은 일반적인 사용법입니다.
