## 무엇인가
CSS Tip은 CSS 트릭을 하나씩 소개하는 짧은 글을 모은 사이트입니다. Temani Afif가 만들었고, 홈에는 최신 팁이 날짜순으로 나열됩니다. 최신 CSS 기법을 짧은 예제로 익히고 싶은 프론트엔드 개발자를 위한 곳입니다.

## 이럴 때 쓴다
- 스크롤 기반 애니메이션이나 그리드 위치 감지 같은 최신 CSS 기법의 구현 예를 찾을 때
- 물결 구분선, 블롭 모양, 커스텀 슬라이더처럼 모양이 있는 요소의 아이디어가 필요할 때
- JavaScript 없이 CSS만으로 해결할 수 있는 방법을 공부할 때
- RSS로 새 팁을 받아 보며 꾸준히 학습하고 싶을 때

## 핵심 기능
- **최신 팁 목록**: 각 팁에 제목, 한 줄 설명, 날짜가 붙어 있으며 최근 항목은 2026년 10월 19일자였습니다.
- **아카이브**: 홈에 보이는 것 외에 301개의 팁이 더 보관되어 있다고 안내합니다.
- **랜덤 팁**: 무작위로 팁 하나를 열어 보는 링크가 있습니다.
- **도구 메뉴**: 상단 내비게이션에 Tools가 있습니다.
- **RSS 피드**: 새 글을 구독할 수 있습니다.

## 시작하는 법
홈에서 최신 팁을 훑어보거나 Archive 메뉴로 지난 팁을 살펴봅니다. 특정 주제가 없으면 랜덤 팁 링크로 시작해도 됩니다. RSS 리더에 피드를 등록하면 새 팁을 따로 확인하지 않아도 됩니다.

## 알아둘 점
- 팁이나 코드의 라이선스는 확인한 페이지에 적혀 있지 않았습니다. 가져다 쓸 때는 About 페이지 등을 확인하세요.
- 사이트에 광고(Advertise)와 후원 링크, 제휴 홍보가 있습니다.
- 같은 제작자가 CSS Shape, CSS Loaders, CSS Generators, CSS Pattern도 운영합니다.
- 글은 영어로 제공되는 것으로 보입니다(2026-10 기준).
