## 무엇인가
CSS Shape는 이미지나 SVG 없이 CSS만으로 도형을 만드는 방법을 모아 둔 사이트입니다. 사이트 소개에 따르면 각 도형은 요소 하나로 구현되며 최신 CSS를 사용하고, 대부분 그라디언트 색을 입힐 수 있습니다. 제작자는 Temani Afif이며, 프론트엔드 개발자와 디자이너가 장식 요소나 UI 조각을 가볍게 만들 때 참고할 수 있습니다.

## 이럴 때 쓴다
- 말풍선, 리본, 탭, 브레드크럼처럼 모양이 있는 UI 조각을 CSS로 구현하고 싶을 때
- 섹션 사이에 물결, 지그재그, 곡선 같은 구분선을 넣고 싶을 때
- 하트, 별, 육각형 같은 기본 도형 코드를 빠르게 찾고 싶을 때
- 이미지 파일을 줄이고 CSS만으로 장식을 처리하고 싶을 때

## 핵심 기능
- **약 75개 도형 목록**: 하트, 별, 육각형, 화살표 같은 기본 도형부터 큐브, 스파클, 퍼즐 조각 같은 장식 도형까지 한 페이지에 나열되어 있습니다.
- **가장자리 처리 모음**: 비스듬한 모서리, 모따기, 스캘럽, 지그재그, 물결 등 박스 테두리를 바꾸는 예가 있습니다.
- **UI 부품형 도형**: 툴팁, 탭, 햄버거 메뉴, 배터리, 와이파이 아이콘 같은 인터페이스 요소가 포함됩니다.
- **도형별 상세 페이지**: 목록의 각 이름이 개별 페이지로 연결되며, 일부는 css-generators.com 쪽으로 이어집니다.

## 시작하는 법
메인 페이지의 도형 목록에서 필요한 이름을 눌러 상세 페이지로 들어갑니다. 상세 페이지에서 해당 도형의 CSS 코드를 확인하고 자신의 프로젝트에 가져다 쓰는 방식입니다. 같은 제작자의 CSS Loaders, CSS Generators, CSS Pattern 등 자매 사이트가 푸터에 링크되어 있어 함께 둘러볼 수 있습니다.

## 알아둘 점
- 메인 페이지에는 가격이나 사용 조건(라이선스)이 적혀 있지 않습니다. 상업적 사용 전에는 각 상세 페이지나 제작자 안내를 확인하는 것이 좋습니다.
- 지원(Support) 페이지 링크가 있어 후원으로 운영되는 것으로 보이지만, 조건은 메인 페이지에 설명되어 있지 않습니다.
- 최신 CSS 기능을 쓰는 예가 많아 브라우저 지원 범위는 도형마다 확인이 필요합니다.
