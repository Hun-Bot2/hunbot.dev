HRD 팀에서 교육에 대한 수기 취합의 불편함이 있어서 이를 통합 플랫폼으로 구축해서 해결하고자 함.

기술적인 고정은 Supabase랑 인프라로 Rocky Linux 9 PM2, nginx reverse proxy 이렇게 고정.

UI 디자인에 대해서는 taste skill을 사용해서 보다 깔끔한 frontend을 구성하고자 함

Claude Design을 사용 -> Prototype 작업 진행, 디자인을 만들 때 한 번에 넣어서 돌리면 완성도가 떨어져서 각 화면마다 프롬프틀르 뽑아서 진행.

Design을 처음에 만들 때 로그인 화면 먼저 만들었는데, Opus를 써야하나 Sonnet을 써야하나 -> 답은 모델에 설명에 나와 있으니 그때 그때 필요한 걸 선택해서 하면 될 듯.

참고한 것은 markusstoeger.com에 나와있는 claude design-uebung-1에 대한 글을 읽고 사용

작성 할 때, 어떤 부분들이 불편했고 이걸 어떤 기술로 해결하고자 했는지, 그에 따른 의사결정 사항은 무엇인지

Claude Design을 사용할 때, 사용하는 프롬프트나 Design System을 어떻게 만드는지 부터 학습이 진행되어야함

## [2026-07-13]

이제는 기록을 좀 꼼꼼하게 남기려고 한다.

오늘의 작업은 기존 2020 ~ 2026년도까지의 교육 수기 데이터를 통합 플랫폼에 넣는 작업을 위해서, 데이터를 정리하는 작업을 진행했다.

데이터상 2023년도 자료 다른 자료들과 달라서 2023은 제외한 채로, 260709 전사인원현황과 2020~2026년도 자료의 사번과 이름을 비교해가면서 데이터 정리를 진행했다.

퇴사자가 있고, 교육 자료에 대한 데이터가 중구난방으로 정리되어 있고, column이 다르기도 하고, 각 셀마다 띄어쓰기가 하나 더 존재하거나 다른 문자 형태로 들어가 있는 데이터도 존재해서, 이런 부분들을 읽어내 DB작업이 편한
데이터의 형태로 바꾸는 것이 1순위였다.

그래서, Column / Value에 해단 정규화 함수들을 먼저 작성하는 작업을 거쳤고, 직책의 경우에는 "팀장" 이상만 작성이 되어 있으며, 다른 사람들은 "0" 또는 공백으로 되어 있었기에 이 부분도 모두 "평사원"으로 채우는 작업을 수행했다.
