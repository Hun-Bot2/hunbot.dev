# Fine-tuning이란?
Fine-tuning은 사전 학습된 모델을 특정 작업이나 도메인에 맞게 조정하는 과정입니다. 일반적으로 대규모 언어 모델(LLM)은 방대한 양의 텍스트 데이터를 사용하여 사전 학습되며, 다양한 언어 이해 및 생성 작업에 활용될 수 있습니다.

그러나 특정 작업에 최적화된 성능을 발휘하기 위해서는, 사전 학습된 모델을 해당 작업에 맞게 추가로 학습시키는 과정이 필요합니다. 이 과정이 바로 fine-tuning입니다.
