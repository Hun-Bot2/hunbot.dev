<u>*[前の記事](../blog_develop_03)*</u>からの続きです。  
前の記事でライトテーマではコードが見えにくい問題があると書きましたが、この部分はCSSスタイルの問題だったため、比較的簡単に修正できました。  
2〜3時間ほど試行錯誤してCSS修正を完了し、次のように見やすく整理しました。

```css
.prose pre.astro-code {
  margin: var(--spacing-8) 0;
  padding: var(--spacing-4);
  border-radius: 0.75rem;
  overflow-x: auto;
  border: 1px solid #e5e7eb;
}
```

## 問題点
- コードハイライトはShikiがテーマに合わせてくれるのに、私が`global.css`で`code`と`pre`に別途色と背景を上書きしていた。
- そのスタイルが**暗い背景 + 白い文字**基準だったため、ライトモードでは文字がほとんど見えなかった。

## 過去のコード
```css
code {
  padding: 2px 5px;
  background-color: rgba(255, 255, 255, 0.1);
  border-radius: 3px;
  font-family: 'JetBrains Mono', Monaco, Consolas, 'Courier New', monospace;
  font-size: 0.85em;
  color: rgb(248, 249, 250);
}

pre {
  padding: var(--spacing-4);
  border-radius: 4px;
  background: rgba(0, 0, 0, 0.3);
  overflow-x: auto;
  margin-bottom: var(--spacing-8);
  font-size: 0.875rem;
  line-height: 1.45;
}
```

## 現在のコード
```css
.prose pre.astro-code {
  margin: var(--spacing-8) 0;
  padding: var(--spacing-4);
  border-radius: 0.75rem;
  overflow-x: auto;
  border: 1px solid #e5e7eb;
}
```

## 何を直したか
- **上書きしていた色を削除**: `code`と`pre`に強制的に白文字/暗い背景を入れていた部分を取り除いた。今はShikiがライト/ダークに合わせた色をそのまま使う。
- **対象を明確化**: `.prose pre.astro-code`に範囲を絞り、ブログ本文のコードブロックだけをスタイリングする。
- **視覚的ガイドだけ残す**: 色ではなく余白、角丸、薄い境界線だけを追加し、ライトモードでも境界が見えるようにした。ダークモードも既存テーマ色を維持する。

### 試験が終わったら追加修正
- 閲覧数カウンターを再度作る必要がある。
