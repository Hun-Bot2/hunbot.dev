# ハッカソン概要

テーマ：生成AI APIを活用したビジネスモデル開発 / 生成アルゴリズムを活用したビジネスモデル開発

**私たちのチームの選択：生成AI APIを活用したビジネスモデル開発**

大学のホームページに告知が掲載されたとき、大学連合ハッカソンであり、ホテルで2泊3日の食事と軽食が提供されると書かれていた。試験が終わったばかりの自分にとっては、休息と開発プロジェクトを同時に進められる良い機会だと思った。

チーム編成は、事前に回答したGoogleフォームをもとに、できるだけ公平に割り当てると主催者から案内された。合計5つの大学が参加し、各チームは5人で構成された。

私たちのチームはまずアイデア出しから始め、以下のような案が出た。

```text

4. 感情日記
5. プロンプト変換器 -> AI向けに整形 [Markdown、複数形式]

   -> 具体化
```

## アイデア：赤ちゃん言葉でけんかするロボット玩具

`https://youtu.be/Tgk9L-6XsvA` の動画に加えて、動くサボテンのおもちゃまで想定して考案したアイデアで、チームメンバーの投票によって選ばれた。

このアイデアについて調査していると、「喃語」には特定の意味がないことがわかり、生成AI APIを活用して作るには不向きだと判断した。

そこでアイデアを変えようとしたが、既存アイデアの調査中に、18か月から3歳の時期に子どもの言語能力が爆発的に伸びるという点を見つけた。そこで方向性だけを変え、対象年齢を18か月から3歳に絞って、より具体的にdevelopしてみようと考えた。

> データ：`https://talkbank.org/ | https://langcog.github.io/childes-db-website/index.html`
> 実際の製品：`https://catius.cafe24.com/`

### 変更後のアイデア：子どもと一緒に成長する対話型ロボット玩具

コアアイデア：

1. 子どもと一緒に成長する -> その年齢に合った発達段階と必要能力を、自社アプリで提供する。
2. 子どもが玩具と会話しながら、言語能力と認知能力を発達段階に沿って確認できるよう、レポート形式で提供する。
3. 18か月から3歳、3歳から4歳、4歳から4.5歳のように、発達段階理論に基づいた適切な会話内容を提供する。
4. 子どもの言語・脳発達を支援する。
5. 子どもが投げたり叩いたりしたときの衝撃に備えたハードウェア設計と、かわいい外観を用意する。

### 課題？

1. 幼い子どもが簡単に玩具を操作できるようにするには？ -> カメラ認識、目立つスイッチなど。
2. GDPR-K（韓国）、児童オンラインサービス関連法
3. アルゴリズムの誤り、解釈リスク -> fallback、モデル学習の多様性［問題：データが十分ではない］
4. 技術と規制
